首次设置管理 Key

服务器将生成一个 32 字符随机管理 Key，写入 config.json，并仅在本次操作完成后弹窗展示。请妥善保存。

两种设置方式：① 在服务器本机（或 SSH 本地端口转发）打开本页，一键生成 32 字符随机 Key； ② 直接在服务器上编辑 config.json，把 gateway.adminKey 设为随机字符串后重启网关。 自动生成仅限本机，避免远程抢先初始化；设置完成后可从其他设备使用管理 Key 登录。
